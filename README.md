# 👋 Hi, I'm Manuel Gil

Independent maintainer of open-source tools used in real-world environments.

This profile exists to show what is being maintained - not to sell a product or a persona.

## 🛠️ What I maintain

I build and maintain tools that reduce friction in everyday technical work:

- **Windows repair & recovery tools** (Reset Windows Update Tool, WSUS utilities, Office cleanup)
- **VS Code extensions** (JSON Flow, Auto Barrel, generators and snippet packs)
- **CLI & npm utilities** used by other tools

Some of these projects are quiet.
Some are used more than people realize.
All of them require ongoing care.

## ⚖️ How this works

I am the author and maintainer.
I review issues and contributions when I can, and I decide what gets built and released.

Merged code means it fits - not that it will ship.
These projects are not a support desk or a company.
